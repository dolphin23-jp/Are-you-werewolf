## ファイル

各 `seedN/` には次のファイルがあります。

- `report.md`、`summary.json`: 実行時の集計
- `transcript-seedN.json`: 集計用の全記録
- `transcript-seedN.md`: 対戦記録を省略なしで読める形にしたもの。各発言のメッセージID・場面・返信先・名指しの質問・公開した結果・字数・非公開メモ、投票の理由・決め手・反対仮説・次点・監査の判定、夜行動の理由と結果、日ごとの朝の死体・票の集計・処刑・霊媒の結果を含みます。「実際の結果（本人には知らされない）」とある行は記録用の神の視点で、本人に伝わるのは占い師の「結果」だけです。
- `calls-seedN.md` / `calls-seedN.jsonl`: 呼び出しごとの記録（席・日・場面・スキーマ・所要時間・トークン・費用・出力）
- `prompts-seedN.jsonl.gz`: 各呼び出しのプロンプトの全文（1行1呼び出し）
- `actions-log-seedN.txt`: Actions の実行ログ（評価ジョブの全文。実行中に表示された進行ログと時刻を含む）

通読した所見は `analysis.md` にまとめています。オーナーの seed 1 レビューの項目ごとの判定と根拠は、seed ごとに `review-check-seedN.md` にあります（点検用のエージェントが、対局時のコミットの記録・プロンプト・コードを読んで書いたもの。主要な主張は `analysis.md` を書くときに確かめ直しています）。
