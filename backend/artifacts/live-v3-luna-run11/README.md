## 何に使うか

**文脈としてだけ使う。** luna での v3 の物差し（成功率 100%、議論1回の平均応答 18.0 秒、
1日あたり公開発言 9.8、定型句率 6.4%、聞き入れ指標の基準線 6/64 など）の出典である。

Claude（`WEREWOLF_LLM_PROVIDER=anthropic`）での対戦は**新しい基準線を一から作る**。
この記録を「変更前」として、Claude の対戦と前後比較しない。理由は二つある。

- モデル側の性質（成功率、応答時間、思考トークン、途中切れ）はモデルを替えると変わる
  （approach-reset §2.1 の注記）。
- コードも違う。この対戦のあとに PR #114〜#116 がマージされた: 引用した他人の結果を
  本人の結果として記録する不具合の修正と公開記録の監査（§10.1）、同じ質問への繰り返し
  返信の修正（§10.2）、評価の誤検出の修正（§10.3）、v3 の既定化、「聞き入れて意見を
  変える」の実装と指標（§10.6）。`report.md` §2 の「人狼が仲間を明示的に狼視」2件は、
  §10.3 で直した誤検出である。

## 制約

- **全文の対戦記録は残っていない。** 元の成果物 `eval-out`（Artifact ID `11261634383`、
  4ファイル: `report.md`・`summary.json`・`transcript-seed1.md`・`transcript-seed1.json`）は
  保持期間14日で失効した。`summary.json` と対戦記録の全文は復元できない。
- **`progress.log` の発言は90字で切れている。** 進捗ログは1行を90字に切り詰める
  （`backend/app/eval/progress.py` の `TEXT_LIMIT`）。公開発言78行のうち34行が末尾「…」で
  切れている（もう1行にある「…？」はモデル自身の表記で、切れていない）。狼・共有チャット
  20行、投票、夜行動は欠けていない。発言の長さや定型句率はこのログから計算し直せないので、
  `report.md` の値を使う。
- **APIキーの断片を伏せた。** `check_llm.py` はキーの先頭4字と末尾2字を表示する。
  `check_llm.txt` ではそれを `[redacted]` に置き換え、長さだけ残した。`LUNA_BASE_URL` は
  Actions が `***` に伏せている。
- 1戦だけの記録で、ばらつきは分からない。
