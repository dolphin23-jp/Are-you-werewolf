## 1. 根本原因の全体像

### R1 手番の組み立て（コード）

- **【事実・設計】冒頭の5席の上限に、義務の発言者も数える。** `MAX_OPENING_SPEAKERS=5` に、結果を持つ席やCO予定の席も入ります。2日目以降は、灰が1〜2席しか冒頭で話せません。点呼は1日目だけです（1-A4・2-A1・3-A1）。

### R3 古い状態が、日付も状態も付かずに持ち越される（プロンプトの提示）

### R5 人狼・狂人にとってのメモ欄の意味が未定義（設計）

### R6 ドクトリンの欠落（v3 のプロンプト）
- **v3 で消えた共通の規則。** legacy には全席共通の「初日占いはランダムで自然。理由の薄さ・COの短さ・強い口調を偽要素にしない。答えた占い理由は聞き直さない」がありました。v3 では村人6席向けの文にしか残っていません。ケント・共有・狩人・人狼には届いておらず、これが 1-B4・1-C3 の主因です。
- **妖狐のドクトリンがない。** 秘匿の指示「本当の目的を漏らさない」の対象が人狼・狂人だけで、妖狐が入っていません（1-C1）。役職カードは「生き残れば勝利する」で、いつの時点で勝つのかを書いていません（5-B2）。
- **人狼の「票の見え方」（身内切り・ライン）、偽占いの「黒を出されたときの受け方」がない**（3-B1・3-B4）。
- **狩人に「黒を吊った夜の霊媒噛み」がない。** 人狼側にだけある、非対称な状態です（4-N1）。
- **用語。** 「3-1」の例に 3-0 がありません。グレーの定義が2つあります。グレランと指定が両立するように読めます。GJ の定義が妖狐の場合を落としています。霊結果による検証を、霊媒が生きている前提で書いています（1-B1・1-B2・2-B5・4-B1）。
- **場面文。** まとめと本指定は、グレランの日でも吊り先を一人求めます。初回意見の選択肢にCOがありません（1-B2・1-B3）。

## 4. オーナーの判断が必要な点

1. **人格の効く範囲**（1-C2・1-C3・3-B4）。人格は口調と話す量だけを変えるのか、判断や手続きの守り方まで変えるのか。前者なら、役目のある手番（進行役・結果を持つ席）に「手順は人格に関係なく守る」をコードで入れ、例文から中身を約束する台詞を外します。
2. **人間らしい誤りをどこまで再現するか**（1-C3・1-B4・2-B8・3-B1）。口調で疑う、少ない材料で吊る、といった誤りを、規則で抑えるのか、ある程度は残すのか。
3. **霊媒の潜伏をどこまで許すか**（1-B3・2-B2）。A: 初日CO を標準にしてコードで義務にする。B: 戦術としての潜伏も許し、事実と促しだけを足す。
4. **共有チャットの目的**（2-N1・1-B5）。A: 翌日の進行を決める場にする。B: 演出だけなら呼び出しをやめる。
5. **少数意見の点検枠の意図**（3-A3・5-B3）。今のまま第三者に反論役をさせるのか、本当の少数派に話させるのか。
6. **ゲートが何を測るか**（1-D・5-A・3-B1。前回お聞きしたもの）。非公開のメモと票の食い違いを「正しさの破れ」とするのか、公開の立場と票の食い違いだけをそう扱うのか。指定に従った、結果を変えない身内切りを不合格から外すか。

### 4.1 オーナーの判断（2026-11-17）

| 論点 | 判断 | 修正への反映 |
|---|---|---|
| 人格の効く範囲 | 口調・量だけ | v3 の人格の層から、判断・手順の軸（考え方の癖・議論スタイル・意見の聞き方）を外す。例文から中身を約束する台詞を外し、口調の見本だけにする。進行役の手順は、手番の構造（弁明の手番・本指定）で支える |
| 人間らしい誤り | 多めに残す | コードで出せる事実の取り違えだけを防ぐ（盤面メモの帰結の行、日付・状態付きの前回メモ、投票の索引など）。legacy の共通規則（口調・初日占い理由を材料にしない）は戻さない。投票欄の規則（人数を根拠にしない等）も、戦略の助言（人狼のライン、狩人の霊媒噛み、偽占いの備え、白の処刑の振り返り）も足さない。用語の定義は事実なので直す |
| 霊媒の潜伏 | 許し、促すだけ | 「霊媒CO: まだなし」を事実として出す。霊媒の席の私的な促し「あなたはまだ霊媒COしていない。17Aでは1日目COが普通」を足す。初回意見の選択肢にCOを入れる。進行役のドクトリンはCOの後だけに出す。COの義務にはしない |
| 共有チャット | 翌日の進行を決める場 | 共有専用の指示（明日の方針・候補・占いの扱い・どちらがまとめるか、狩人は読めない）を作る。前夜のチャットを翌日の共有2人に届ける |
| 少数意見の点検枠 | システムが割り当てない | 「誰か1人に話題が集中すると、バランスを取ろうとする人が自然に出てくるのが人間の議論。その自然な再現を望む」。強制の点検枠を廃止する。その日まだ話していない席に一言の手番を配り（話す機会だけを渡し、内容は指定しない）、反論は自然に出るのに任せる |
| ゲート | 公開の立場と票で測る | 不合格は「卓で自分が名指しした吊り先」と票の、説明のない食い違いだけにする。非公開のメモとの食い違い（`memo_target_unspoken`）、基準なし（`no_basis`）、指定に従った結果を変えない身内切りは、不合格から外して引用付きの一覧にする。投票先と理由の食い違いは、新しく一覧に出す |
